One status that says where the request is, and who has it

Today two columns (approval and fulfilment) become a different label ladder on each page. The redesign derives one request status from both, keeps per-line detail on the request page, and adds request_* entries to theming/status-map.php so every badge is themed, has an icon and never relies on colour alone.

Structure

Employee

Request items→Draft request→My requests→Request page

My requests tabs: Active · Needs you · Finished. The navbar shows "Draft · 3" only while a draft has items.

Approver

Approvals→Decide

Tabs: Waiting for me · Overdue · Decided by me. Same RequestQueues query as the menu badge.

Storekeeper

To issue→Issue items·Issue register→Record

Tabs: Ready · Partly issued · Returns to receive. Oldest and needed-soonest first.

National administrator

Administration›Rules & settings›Request rules

One rule set for every office (requests.configure is national). The breadcrumb no longer sits under Approvals (today /gov-requests/admin/settings/policies).
